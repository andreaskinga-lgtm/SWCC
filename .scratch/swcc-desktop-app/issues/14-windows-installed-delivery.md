# 14: Deliver and exercise the Windows 11 x64 installer

**What to build:** The worker can install and run the complete application under their Windows 11 x64 user account without development tools, understand unsigned-launch restrictions, and install a later build without losing records or evidence.

**Blocked by:** 10: Export a self-contained annual portfolio with original evidence; 13: Restore the whole dataset with interruption-safe recovery.

**Status:** ready-for-agent

- [ ] Produce the native Windows 11 x64 per-user installer with the approved unsigned initial delivery, pinned build tooling, production assets, source PDFs, fonts, PDF worker, and compatible native SQLite components.
- [ ] Verify the installed application rather than only compilation or an unpacked development run. It opens without a development server/tools and uses OS-user-local durable storage.
- [ ] Exercise disconnected year/draft editing, shared goals/activities, review tracking, evidence PDF/image previews, forms PDF/portfolio ZIP export, full backup, validated restore, and restart recovery from the installed application.
- [ ] Exercise native evidence/export/backup/restore dialogs, explicit external-document opens and failures, online resources browser-launch behavior, window shutdown/autosave protection, and single-instance handling.
- [ ] Check C's shell and each destination, including relationship-first dashboard, plan connection strip/single editor, review, assessment, year list, and backup/restore. No variant controls, sample records, simulations, banners, state inspector, or developer reset tools ship.
- [ ] Install a later build over a populated installation and verify database/evidence, references, dates, review/completion, and declarations survive. A migration failure is reported without resetting the dataset.
- [ ] Provide accurate unsigned-install/first-launch guidance for SmartScreen and possible Smart App Control or managed-device restrictions. Do not promise bypasses that always work or add signing/automatic updating as prerequisites.
- [ ] Record installer identity, test environment, actual installed outcomes, failures, and limitations separately from automated checks/build success. If a Windows execution environment is unavailable, identify that blocker and leave installed acceptance unverified; compilation alone cannot resolve this ticket.
