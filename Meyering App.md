# Meyering App

Every year, social workers need to put together a package that tracks that they've completed their Continuing Competence Program tasks. They need to keep these packages for at least 10 years.

## Steps involved in completing the Continuing Competence Program

### Step 1
Review Code of Ethics PDF and complete a checklist of each section that you've reviewed.

### Step 2
Complete self assessment form. Currently in a pdf chart.

### Step 3
Complete a Professional Development Plan (PDP). This is another PDF chart centred around creating goals, tracking activities/experiences you've completed relating to those goals, and then explaining how those activities/experiences have helped with that goal. The activities/experiences can include Classes, Groups, Websites, PDFs, and Books. 


## How the application should function
The way I'm envisioning this app working is based around year 'Packages'. On the initial screen you should see all the packages laid out chronologically. When you click into one, you'll be taken to a screen that essentially acts as the 'dashboard' for the package. You can use it to track your progress for that year, and go into each 'step' section to modify/add to them.

The flow for the first step should allow the user to read through the Code of Ethics PDF, and automatically check off each section in the checklist when it has been read. The page you're on in the PDF should be tracked so you can pick up where you left off in another session.

For the second step it should be fairly simple. The first 3 sections of the self assessment form should be Text areas that allow you to fill in the information. The 4th section is a series of checkboxes. However the last section of step 2 involves creating learning goals, which are objects that will feed into step 3 to be used further.

The third step is the most involved. This will be an 'object' based flow with relationships between them. Essentially you'll start by using the goals created in step 2, which are the highest level objects. You can also make 'Activities/Experiences' that can either relate to the existing goals, be used to create new goals, or just be 'orphaned'. The 'Activities/Experiences' should be able to have 'Evidence' attached to them. The evidence would be things like Links, PDFs, or even just text that could be used to store things like names of books or contact information. Each activity should also have a section for the 'Application to Practice' which is just a text field that allows you to explain how this Activity/Experience will benefit your ability to practise and achieve your goal.

The goal of the user interface should be to make this information easy to enter and keep track of, rather than trying to copy the layout of the original pdf charts/forms. However, there should be an 'export' button for each package that allows you to easily export the information in the package back into the layout that the college expects (The PDFs).
