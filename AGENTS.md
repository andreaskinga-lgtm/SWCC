# Agent instructions

## Agent skills

### Issue tracker

Issues are local markdown files under `.scratch/<feature>/`. Before ticket operations, read `docs/agents/issue-tracker.md`.

### Triage labels

Use the default triage roles and `resolved` for completed tasks. Before triaging or changing ticket status, read `docs/agents/triage-labels.md`.

### Domain docs

Single-context: root `CONTEXT.md` and `docs/adr/`. Before exploring the codebase, read `docs/agents/domain.md`.
